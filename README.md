A cinematic esports portfolio showcasing **MohammadOne**, a Dota 2 Position 5 / Hard Support player. This website highlights my signature heroes, support playstyle, competitive mindset, and player profile through a dark, immersive design inspired by the world of Dota 2.

## About

I play **Position 5 — Hard Support**, focusing on vision control, team protection, map awareness, strategic positioning, and creating opportunities for my team.

My philosophy is simple: a great support does more than help win fights — they help make those fights winnable before they even begin.

## Signature Heroes

- **Ringmaster** — Disruption, utility, and tactical control.
- **Undying** — Teamfight presence, durability, and frontline support.
- **Shadow Shaman** — Crowd control, lockdown, and objective pressure.
- **Warlock** — Teamfight initiation, sustain, and area control.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS recommended)
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/mohammad-mesgarzadeh/mohammadone-dota2.git
```

Navigate to the project directory:

```bash
cd mohammadone-dota2
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

Build the project:

```bash
npm run build
```

Run the production build locally:

```bash
npm run preview
```

If the project defines these scripts, you can also run:

```bash
npm run typecheck
npm run lint
```

### Deployment

This project is deployed using GitHub Pages.

To build and deploy the latest version, run:

```bash
npm run deploy
```

The deployment script builds the project and publishes the generated files from the `dist` directory to the `gh-pages` branch.

## Design Philosophy

The visual identity combines deep charcoal backgrounds, crimson accents, muted gold details, and Dota 2 artwork to create a focused, cinematic esports experience.

The goal is to communicate strategic discipline, awareness, and the impact of a support player — not just individual highlights.
